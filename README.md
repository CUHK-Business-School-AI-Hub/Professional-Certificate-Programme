# Professional Certificate Programme

CUHK Business School’s Professional Certificate in Artificial Intelligence for Business uses this repository to share teaching materials. Each course has its own folder on the `main` branch. The README in each folder gives instructors the teaching sequence and points personal agents to the files behind it.

## Inside Building AI-Powered Ventures

Participants run a product-monitoring workflow in Codex, then build a replenishment dashboard using simulated sales and inventory data. In the second version of the dashboard, a copilot helps users interpret business context and review proposed changes. Both exercises apply the Delegate → Evaluate → Coach loop.

- **Teaching the class.** The Day 1 deck has 83 slides. The afternoon outline covers slides 45–83 and identifies when to introduce each exercise and release the reference answers. [Slides](Building%20AI-Powered%20Ventures/slides/AI-Ventures-202612-Slides-1.html) · [Instructor notes](Building%20AI-Powered%20Ventures/notes/README.md)
- **Preparing for class.** The syllabus covers the course requirements. The illustrated API guide walks participants through setting up access for the copilot exercise. [Syllabus and setup guides](Building%20AI-Powered%20Ventures/guides/README.md)
- **Reviewing the reference products.** Use the worked examples and verification steps to inspect what learners build. [Product intelligence workflow](Building%20AI-Powered%20Ventures/reference-products/case1/README.md) · [Replenishment dashboard and copilot](Building%20AI-Powered%20Ventures/reference-products/case2/README.md)
