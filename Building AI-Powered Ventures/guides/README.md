# Syllabus and preparation guides

1. Read [the syllabus](Building%20AI%20Powered%20Ventures%20Syllabus.docx) for course requirements and assessment.
2. Use [Codex Desktop Getting Started Guide](Codex%20Desktop%20Getting%20Started%20Guide.pdf) to install, sign in and complete a local starter task. Its dated illustrations may differ from your current app.
3. Follow [API Access Guide](API%20Access%20Guide.pdf) to claim included Pro API credits, create a key, save it in the backend and complete one small test.

The course assumes learners bring their own eligible paid ChatGPT Pro plan with Codex access. “Codex Pro” is shorthand in classroom discussion; the credit benefit is attached to the eligible ChatGPT subscription. Activate the paid subscription at least seven days before claiming. Sign in with the same email and choose an API organization you own. Confirm the actual grant and expiry in that organization. Official eligibility rechecked on 18 November 2026: [OpenAI benefit guide](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions).

The guide prioritises OpenAI. Its DeepSeek section is an optional fallback with an instructor-suggested starting budget of about HK$10, not a verified minimum top-up. The supplied Case 2 app uses OpenAI; another provider requires an integration change. A model API key is required for the copilot, not the ordinary dashboard or the Codex-hosted Case 1 workflow.

Store the key locally in `.env`, keep it out of chat and frontend code, and do not include it in a shared ZIP. A positive grant balance and one successful API response are the completion checks.
